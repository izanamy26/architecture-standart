#### АБС

1. Разработка и внедрение механизма предоставления данных о ставках по депозитам системе кол-центра и партнёрскому кол-центру.
2. Настройка регулярного обновления данных о ставках в системе кол-центра и партнёрском кол-центре.
3. Обеспечение безопасности передачи данных о ставках (шифрование).

#### Система кол-центра

1. Интеграция с АБС для получения актуальных ставок по депозитам.
2. Разработка механизма доступа сотрудников кол-центра к данным о ставках (интерфейс).

#### Партнёрский кол-центр

1. Налаживание процесса получения актуальных ставок по депозитам в виде файлов от АБС.
